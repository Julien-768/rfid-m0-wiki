## Assembly file

The device assembly is described in the assembly file "ASSEMBLY.cfg" located on the SD card.

??? "Assembly file with example values"

    ```
    {,
    "uid_powerboard":"PB202303001",
    "uid_tectus":"202124001",
    "uid_rfid_sensor":"2303002591056",
    "uid_software":"rfid_m0.code.2.0.0-rc.2",
    "uid_experiment":"202303YH001"
    }
    ```

The file is written as a [JSON string](https://developers.squarespace.com/what-is-json), take care to keep quotes and commas intacts when modifying the file.
