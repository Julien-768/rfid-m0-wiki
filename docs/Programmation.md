# Comment savoir si les LEDs fonctionnent ?

1. Clic sur "Visual Studio Code" sur le bureau
2. Fichier -> ouvrir dossier ''Ce Pc > documents > sources -> clic sur feather_m0
3. Brancher la carte vers le PC
4. Allumer l'interrupteur (gros bouton qui s'enfonce) puis le bouton de la LED
5. Uploader "PlatformIO : Upload"
6. Cliquez sur "PlatformIO : Serial Monitor"

Lorsqu'on passe la main et la retire, deux messages s'affichent " Broken beam puis restored sur la LED IR 1 et LED IR 2), donc les 2 LEDs fonctionnent !
