
# Battery management

## Reload a battery

To reload a battery, preferably use a dedicated battery charger :

1. Select the battery **technology** (Lead or Li-Ion)
2. Select the load mode : **Charge**
3. Select the **number of cells** :
    1. 1 cell for a Li-ion battery (3.6V)
    2. 6 cells for a Lead battery (12V)
4. Define the **load current** : A typical value is C / 3 where C is the capacity of the battery in A.h. In the case a lower current is specified on the battery datasheet, use this value.   
For the lead battery "RS PRO 174-8857", use 1.5A as max current.
5. Start the process by a long press on Start / Enter button

## Store a battery

When a battery is planned to be stored for a certain time, you have to set it into **Storage mode** to optimize its lifetime :

1. Connect the battery to the battery charger
2. Select the battery **technology** (Lead or Li-Ion)
3. Select the mode **Storage**
4. Select the **number of cells** and the **max current** : Use the same values as for the reload
5. Start the process by a long press on Start / Enter button
