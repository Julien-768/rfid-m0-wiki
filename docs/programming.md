# Programming

1. Open the code folder in [Visual Studio Code](vscode://vscode.git/clone?url=https%3A%2F%2Fgitlab.in2p3.fr%2Frfid_m0%2Frfid_m0.code.git). Give some time for the dependencies to be automatically downloaded once the code repository is cloned if it is a first time use.
2. Connect the Feather M0 to the computer using a USB cable
3. Cick on "PlatformIO : Upload"
4. Cick on "PlatformIO : Serial Monitor to check the initialisation messages
