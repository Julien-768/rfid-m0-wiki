# Device description

The purpose of this system is to monitor certain birds. The entrance of a nest box is equipped with sensors to detect the passage of individuals and read their RFID tags (if existing). All this data is collected on a memory card with a timestamp.

Optionally, the nest box door can be closed to capture targeted individuals: None, All, specific RFID tag, or untagged.

The entire system is contained in a door compatible with [Schwegler nest box 2M](https://www.schwegler-natur.de/portfolio_1408366639/nisthoehle-2m/?lang=en).

## System Components and Features

### 1 - Entrance Components

The entrance of the nest box incorporates two infrared transmitters/receivers as well as an RFID antenna.

**Note:** The IR sensor noted as "IR 1" in the record file is the one mounted at the entrance (exterior side).

### 2 - Bottom Components

The bottom of the nest box allows the user to interact with the system and its battery:

- A main switch button: Used to connect/disconnect the system from the battery.
- A switch button: Used to power on/power off the system or get the battery status.
- A red LED: Used by the system to interact with the user.
- A mini-USB port: Used to recharge the internal battery or connect an additional battery to extend autonomy (power bank, solar panel, etc.).
- A ring: Used to hold a power bank via a carabiner.

By sliding the technical door, it is possible to access:

- A slot for the micro-SD memory card.
- A CR1220 3V battery for the Real-Time Clock.
